ติดตั้งโปรแกรมช่วยโหลด (ครั้งเดียว)

เว็บดึงไฟล์จาก YouTube เองไม่ได้ ต้องมีโปรแกรมเล็กๆ บนคอม (ใช้ yt-dlp) คอยโหลดให้ ทำตามนี้บน Windows:

  1. ติดตั้ง Python จาก python.org — ตอนติดตั้งให้ติ๊ก Add python.exe to PATH
  2. เปิด PowerShell แล้วพิมพ์ทีละบรรทัด:
    winget install --id DenoLand.Deno -e
    winget install --id Gyan.FFmpeg -e
  3. ดาวน์โหลด 2 ไฟล์นี้ไว้ในโฟลเดอร์เดียวกัน: klipded_helper.py และ start-helper.bat
  4. ดับเบิลคลิก start-helper.bat (ครั้งแรกจะติดตั้ง yt-dlp ให้เอง) แล้วเปิดหน้าต่างดำทิ้งไว้
  5. กลับมาที่เว็บแล้วกด “ลองเชื่อมต่ออีกครั้ง” — ถ้า Chrome ถามขอสิทธิ์เข้าถึงอุปกรณ์/แอปในเครื่อง ให้กด อนุญาต

ไม่อยากติดตั้ง? โหลดไฟล์วิดีโอด้วยวิธีอื่นแล้วลากไฟล์มาวางในเว็บก็ได้เหมือนกัน
